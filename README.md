# 📝 Text Summarization Application

A simple and professional **Text Summarization Application** built using Python, Natural Language Processing (NLP), Hugging Face Transformers, and Gradio. The application automatically converts long paragraphs or articles into short and meaningful summaries.

## 🚀 Project Overview

The Text Summarization Application uses a pretrained **BART (Bidirectional and Auto-Regressive Transformers)** model to analyze input text and generate a concise summary. The application provides an easy-to-use web interface through Gradio and can be executed directly in **Google Colab**.

## 🎯 Objectives

* Automatically summarize long text.
* Reduce lengthy information into concise content.
* Demonstrate NLP and Transformer-based text processing.
* Provide a simple and interactive user interface.
* Run the application easily using Google Colab.

## 🛠️ Technologies Used

* **Python**
* **Natural Language Processing (NLP)**
* **Hugging Face Transformers**
* **BART Model**
* **PyTorch**
* **Gradio**
* **Google Colab**

## ⚙️ How It Works

1. User enters a paragraph or article.
2. The application tokenizes the input text.
3. The pretrained BART model processes the text.
4. Important information is identified.
5. A concise summary is generated.
6. The generated summary is displayed in the Gradio interface.

## 📌 Features

* Simple and user-friendly interface
* Automatic text summarization
* Pretrained Transformer model
* Supports long paragraphs and articles
* Runs directly in Google Colab
* No manual model training required

## ▶️ How to Run

1. Open **Google Colab**.
2. Create a new notebook.
3. Copy the project code into a single cell.
4. Run the cell.
5. Wait for the pretrained model to load.
6. Open the Gradio link displayed by Colab.
7. Enter your text.
8. Click **Summarize Text**.
9. View the generated summary.
